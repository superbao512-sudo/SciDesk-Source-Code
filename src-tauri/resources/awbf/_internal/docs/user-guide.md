# AWBF 2.0 使用说明

默认进入 DOS 贡献可视化。添加 PDOS 文件或打开计算目录，核对来源和 E_F，即可在图上查看元素、壳层、轨道贡献；无需先创建工作区。

## 调整 DOS 图

点击“筛选”展开元素→壳层→轨道→原子列表。默认“参与统计”模式会改变积分通道集合，因此改变百分比分母；“仅显示”模式只隐藏曲线和对应柱子。搜索只查找树节点，Top N 只改变显示数量。图下摘要持续标示当前模式和统计通道。

横向拖选 PDOS 曲线中的范围可更新积分窗口；也可使用图上方的数值输入和预设。撤销可恢复之前的积分范围。积分仍按原规则处理窗口内已有采样点，不插值补边界；采样过少时显示警告。工具栏缩放和平移只改变显示。

点击柱子可高亮对应曲线，点击空白恢复。显示抽稀保留主要极值，仅影响绘图；原始完整数组参与计算。PNG/PDF 导出附带 CSV、JSON，记录窗口、来源、参考和筛选参数。请使用新文件名以保留旧导出。

## 生成建议或检查拟合

在 DOS 页点击“用当前数据生成投影”，切换到 Wannier 分析。原生读取数据会携带当前统计轨道、完整精度 E_F 和积分窗口。旧导出表仍可走原有流程，正式分析使用完整文件；界面会明确说明旧流程不传递轨道子集筛选。

正式投影需要同源的完整结构；只补齐缺少项。原生能带通过文件自身证据或明确填写的能量、自旋及同源依据读取。无证据的零点、单位、磁性和 k 路径不能从文件名或数据范围推断。已知结构、E_F、k 点冲突不能用勾选覆盖。

选择“生成初始投影”后可以继续推荐窗口；也可直接选择“推荐能带与窗口”并给出目标轨道数。已有 Wannier band 时选择“检查已有拟合结果”。原投影、num_wann、窗口建议、逐点匹配、误差和 good/warning/bad 判断来自原计算核心。

DOS 页使用 E−E_F；完整引擎结果及窗口沿用绝对 eV。规范路线只按明确的模型元数据做一次相对→绝对换算，不使用旧文件名或数值范围猜零点。

## 查看诊断与人工窗口

规范拟合运行完成后，可“交互查看原匹配误差”：原始 DFT/Wannier 对照、沿 k 误差、匹配带×k 热图，以及明确标注的局部辅助统计。显示缩放不会重算或覆盖原质量标签。热图使用原引擎实际匹配关系。

人工窗口先预览，再点击应用到新会话。下次运行另存 `manual-overrides.json` 和 `manual-window.win`；原算法建议仍保留在报告中，人工值不冒充算法推荐。

顶部“只读运行诊断”可打开明确支持的 `.wout`、Hamiltonian、PROCAR 或声子格式。局域化指标不能证明能带拟合好；HR、Fat band、声子图属于有限输入契约的只读辅助工具。Berry、拓扑、费米面、外部求解器执行仍需独立理论与物理验收，未作为已完成科研能力开放。

## 项目历史和数据

每次运行建立独立 `analysis-runs/时间-目标-编号` 目录，保存输入副本、参数、来源和结果。历史入口支持搜索、状态过滤、打开记录、恢复到新会话和两次记录对比。旧记录只读，恢复不会覆盖原运行。没有可信运行状态的旧记录标为 legacy，不能仅凭存在图片判成功。

取消会保留已有副本及部分输出并标记 cancelled/incomplete；失败不能显示成功。程序不会执行 VASP、QE、Wannier90 或 EPW。清空解析缓存不会删除输入、结果或历史。

SciDesk 工具包解压后在工具页选择包含 `scidesk-tool.json` 的 AWBF 文件夹添加；完整保留 EXE 与 `_internal`。无需 Python。SCI 项目数据库、嵌入宿主页面与跨工具共享没有新增接口，本工具仍以独立 Windows 窗口运行。默认数据使用 SciDesk 提供的独立工具目录。

## 支持范围与证据

格式细节及未支持变体见随包的 VASP、QE、band、diagnostics 说明。官网固定版本样本属于格式证据，合成 fixture 属于程序验收；它们不替代独立真实物理验证。新版本发布报告会分别列出已运行测试、EXE/SciDesk 验证及缺少的数据证据。
