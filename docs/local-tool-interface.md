# SciDesk 本地工具接口 v1

在「工具」页面，**添加网页工具**用于网址；**添加工具**用于加载本地工具文件夹。

当前接口是本地工具的注册与启动协议，支持 Windows 桌面 EXE 和本地 HTML 页面。工具使用自己的界面。它不在 SciDesk 主进程中加载 DLL，也不为第三方代码提供数据库或项目文件访问 API。

## 工具文件夹

将 `scidesk-tool.json` 放在文件夹根目录，使用 UTF-8 编码：

```json
{
  "schema_version": 1,
  "id": "my.research.tool",
  "name": "我的小工具",
  "version": "1.0.0",
  "description": "显示在图标下方的简短说明",
  "runtime": "exe",
  "entry": "MyTool.exe",
  "args": [],
  "icon": "icon.png"
}
```

| 字段 | 约定 |
| --- | --- |
| schema_version | 必须为整数 1 |
| id | 稳定标识，3–80 位英文字母、数字、点、横线、下划线，以字母开头 |
| name | 必填，1–80 字 |
| version | 必填，例如 1.0.0，用于显示 |
| description | 可选，最多 500 字 |
| runtime | `exe` 或 `html` |
| entry | 文件夹内部的相对文件路径，不使用绝对路径、上级目录、符号链接或目录联接 |
| args | 可选字符串数组，EXE 最多 32 项，每项最多 4096 字节，按独立参数传入，不经命令行解释器；HTML 不接受参数 |
| icon | 可选，相对 PNG/JPEG/WebP 路径，最大 2 MB；省略时显示默认图标 |

本地网页工具使用 `"runtime": "html"`、`"entry": "index.html"`。页面和依赖资源保存在同一工具文件夹，使用系统默认浏览器打开。依赖 HTTP 服务、服务器 API 或跨域请求的网页不属于静态 HTML 入口；这类工具需自行提供启动器。

EXE 工具应自带所需资源与运行依赖。Python 工具可先打包成独立 EXE，再注册。SciDesk 不自动安装 Python、依赖包，不运行 `.bat`、PowerShell 或任意脚本清单。

## 添加与启动

1. 点击「添加工具」，选择或粘贴工具文件夹路径。
2. 点击「读取工具」，确认名称、标识、版本、类型和入口。
3. 点击「添加到工具页」。此时只保存记录及图标副本，不启动程序，不复制工具文件夹。
4. 点击工具图标启动。EXE 的工作目录为工具文件夹，HTML 交给默认浏览器。

EXE 启动时设置：

- `SCIDESK_TOOL_API_VERSION=1`
- `SCIDESK_TOOL_DATA_DIR`：SciDesk 数据目录下为该入口分配的独立数据文件夹，首次启动时创建。

工具在当前 Windows 用户权限下独立运行，具有普通本地程序的文件和网络能力；这里不提供第三方代码沙箱。只加载你信任的工具。

## 更新与移除

同一 `id` 再次添加会更新已有入口，保留其列表位置；右键「重新加载工具」也可更新路径或版本。清单或入口文件变化后，启动会要求重新读取并确认。预览与添加之间文件发生变化时，该次添加会拒绝。

工具文件夹移动或入口失效时，选择新位置重新加载。移除只删除 SciDesk 的入口和自有图标副本，不删除原始工具文件夹，也不删除该工具的数据目录。

网页工具会通过数据库 v1 → v2 迁移保留其名称、网址、说明和原有图标。
