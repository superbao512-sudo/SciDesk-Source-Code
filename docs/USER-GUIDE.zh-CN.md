# SciDesk Windows 使用指南 · 0.3.2

## 首次启动

将完整的 Windows x64 发行包安装或解压到当前账户可写的目录，启动 `scidesk.exe`。保留程序旁边的资源目录，包括整套 `awbf`。桌面界面使用 Microsoft Edge WebView2。

首页可以从搜索框查找内容，按 Ctrl+K 可快速回到搜索。点击副标题或个性文字旁的编辑按钮可以修改首页文案。收起侧栏可给编辑区留出更多空间，图标仍可用于导航。

## 项目与文献检索

1. 在「项目」中新建项目，或导入已有的本地项目文件夹。选定目录后先检查文件树，确认关联的是预期项目。
2. 在文件树中右击目标进行复制、重命名或删除。重命名会改变磁盘上的名称。删除前核对目标并确认，误删后先查看 Windows 回收站。复制文件适合制作计算输入的工作副本。
3. 在项目内打开文献检索，输入研究问题或关键词，根据需要选择来源、年份与结果数量。先用较宽的主题检索，再用材料名、方法名缩小范围。打开原始记录核对作者、年份和 DOI。可将结果导出为 Markdown 供阅读，或导出 JSON 作后续处理。在线来源的响应速度和记录数可能不同。

## 期刊、学术主页与推送

在「期刊」的学术主页区域连接自己的 Google Scholar **个人主页**。个人主页链接通常含有 `user=`。如果 SciDesk 连接失败，在浏览器打开该主页，展开希望导入的论文，在页面空白处右击「另存为…」（Ctrl+S），选择 HTML。在 SciDesk 的「更换主页」区域点击「导入主页 HTML」，选择保存的 .html 或 .htm 主文件。导入后核对作者、研究方向和论文列表。离线文件只包含保存时页面已有的内容，更新快照需要再次保存并导入。

「为我推荐」适合跟踪与学术主页方向相关的文章。「自定义关键词检索」适合独立追踪具体主题，例如 `phonon thermal conductivity`。先分别检查两处关键词，再刷新文章。如果列表为空，可先检查主页研究方向、放宽检索词并确认网络可达。在线获取新文章需要网络。

## 想法、手册与学习

- **想法**适合记录尚未形成项目的研究问题。将笔记、关联和附件放到同一主题下，保留原始数据的位置，便于后续追踪。
- **手册**可关联现有本地文件夹。右击文件或子文件夹可复制、重命名或删除。「解除关联」只移除 SciDesk 中的入口。要实际删除磁盘内容，使用「删除」并在确认框中核对路径。
- **教学手册编辑器**可从工具页直接开始写作，也可以从手册进入。左侧写 Markdown，右侧查看排版。用 `##` 建立小节，行内公式可写 `$E=\hbar\omega$`，插图时保留配套图片文件。完成各章并保存后，使用「编译整本」按章节生成整本预览，再选择 HTML 或 PDF 导出。搬迁手册时复制整本目录及图片。
- **导入自己的书签。** 在 Chrome 书签管理器或 Edge 收藏夹的菜单中导出 HTML。可先将文件和「学习 → 导入自己的浏览器书签」中的提示词交给 AI，下载整理后的书签 HTML，再在 SciDesk 中选择文件。核对分类后确认导入。也可直接导入浏览器原文件。重复网址会跳过。
- **学习**按主题查找网站，例如 VASP、Quantum ESPRESSO、声子和热输运。了解参数定义先看官方文档，首次上手可看入门教程，复现流程时再打开计算实例。

## Wannier 能带与 DOS 分析

打开「工具 → Wannier 能带与 DOS 分析」。AWBF 在独立窗口运行，可以同时回到 SciDesk 查看笔记。

1. 在 DOS 贡献可视化中载入计算目录或投影态密度文件（PDOS）。用 VASP 或 Quantum ESPRESSO 数据时，核对识别出的自旋、元素和轨道通道，以及每份文件的来源。
2. 确认能量列是绝对能量还是已减去费米能的相对能量。若已使用相对能量，避免再次平移。在已对齐的数据上选择积分范围，例如费米能上下 2 eV。
3. 查看轨道积分和占比，点击柱子查看对应曲线。「参与统计」决定占比分母，「仅显示」及 Top N 控制图面显示。只有所选通道完整时，才宜将占比解释为全部投影态的分布。
4. 需要生成投影时，补充同一计算的结构。分析能量窗口时，补充对应的 DFT 能带和目标轨道数。检查拟合前核对 DFT 与 Wannier 能带的 k 路径、单位和能量参考，再查看匹配误差。不同材料或路径的数据不能直接比较。
5. 导出图像、CSV 和参数 JSON，给输出取新名称。通过分析记录或历史查看输入、参数及结果。Wannier90 计算本身需在相应计算环境中运行。

## 其他工具

| 工具 | 常用操作 |
| --- | --- |
| 科研数据快速绘图 | 打开表格数据，指定横轴和纵轴，按需要叠加曲线。导出前核对单位、列名和图例。 |
| PDF 阅读与摘录 | 打开 PDF，选择原文或框选插图，保存摘录和批注。物理术语译文需对照原文。纯扫描页可能无法直接选择文字。配置联网翻译模型时，选中的文字会提交给配置的服务。 |
| 物理单位与公式速查 | 按 Alt+U 打开换算，先选物理量，再指定输入和输出单位。 |
| 曲线数据提取 | 导入图像，用已知刻度标定坐标轴，再沿曲线取点并导出。核对坐标轴采用线性还是对数刻度。 |
| 高级截图 | 选择区域、标注或贴图；通过工具卡的设置按钮配置捕获选项。 |

## 备份、升级与故障排查

关闭 SciDesk 及分析工具后，备份程序旁的整个 `SciDeskData`。其中包括数据库、期刊缓存、想法和附件、默认项目及导出文件。另行备份外部关联的项目、手册和学习资料。搬到新电脑时，先恢复完整目录，再启动并检查各个外部关联。

| 遇到的问题 | 检查方法 |
| --- | --- |
| 项目文件消失或手册打不开 | 在资源管理器核对原盘符与路径；若移动过目录，重新关联新位置。 |
| Wannier 工具无法启动 | 核对发行包中 `awbf/AWBF-Desktop.exe` 和同目录的 `_internal` 均存在。重新解压完整发行包可补全缺失资源。 |
| 新文章没有显示 | 离线 HTML 可恢复个人主页信息；文章检索仍需网络。检查关键词并重新刷新。 |
| 换电脑后资料缺失 | 核对复制的 SciDeskData 是否与正在运行的程序同级，以及外部资料是否已搬迁。 |

报告问题时附上 SciDesk 版本、Windows 版本、复现步骤及脱敏截图。涉及科研数据时，可提供能复现问题的小样例。
